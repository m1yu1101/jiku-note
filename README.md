# ジクノート

就活の「軸」を見つけて、企業を自分の物差しでくらべるための決断ノートです。

**▶ 使ってみる：https://m1yu1101.github.io/jiku-note/**

スマホのブラウザで、インストールなしで使えます。

## 作ったきっかけ

就活をしていて、「何を基準に会社を選べばいいのか」が分からなくなりました。
就活サイトには企業の情報があふれていますが、それを**自分にとって合うかどうか**で整理する道具がありませんでした。

また私には、体調などの事情で「在宅勤務ができる」「時差出勤ができる」のような、働くうえで譲れない条件があります。
こうした条件は、給料や成長のように「他の良さで補える」ものではありません。
そこで、点数とは別に「譲れない条件」を判定できるアプリを作りました。

## できること

| 機能 | 内容 |
|---|---|
| 軸の診断 | 8つの価値を二択で総当たり（28問）して、自分が大事にしたい軸の順位を出す |
| 企業ノート | 気になる企業を上位4つの軸で1〜5点評価し、「合う度」の高い順に並べる |
| わたしの条件 | 体調や生活のために譲れない条件を「あり・なし・未確認」で記録。必須条件を満たさない企業には警告を出す |
| 直感とのズレ | 条件の合う度（頭）と直感（気持ち）のズレから、まだ言葉にできていない本音に気づかせる |
| バックアップ | データをファイルに書き出し・読み込みできる |
| AIアシスト ※ | 採用ページのリンクから企業研究、点数と条件の提案、逆質問の作成 |

※ AIアシストは、claude.ai 上で開いたときだけ動きます（後述）。

## しくみ

### 1. 二択の総当たりで軸の順位をつける

いきなり「何を大事にしたい？」と聞かれても答えにくいので、二択をくり返す形にしました。
8つの価値から2つずつ選ぶ組み合わせは 8×7÷2 = 28 通りです。
選んだ方に1点、「同じくらい」は両方に0.5点を入れます。

### 2. 合う度は「重み付き平均」

```
合う度(%) = Σ(重み × 評価) ÷ Σ(重み × 5) × 100
```

重みは診断で出た各軸の点数です。大事な軸ほど、評価が合う度に強く効きます。

### 3. 「譲れない条件」は点数に混ぜない

在宅勤務を合う度の1項目にすると、給料や成長の点数が高いだけで、在宅勤務ができない企業でも上位に来てしまいます。
そこで条件は点数とは別に判定し、必須条件が「なし」の企業は、合う度が高くても一覧の下に回して警告を出します。

### 4. AIの使いどころを分ける

AI機能を設計するときは、情報の種類ごとに守り方を変えました。

| 情報の種類 | 例 | 守り方 |
|---|---|---|
| 計算した数字 | 合う度、条件チェック | コードで計算し、AIには触らせない |
| 調べた事実 | 在宅勤務制度の有無 | 出典と根拠の一文を表示し、最後は人が確認して反映 |
| 考え・提案 | 逆質問 | AIに任せる。使うかは人が判断 |

企業研究は、決まった順番で動く「ワークフロー」型にしています。

1. コネクタ（Parallel Search の `web_fetch`）で採用ページを読む
2. AIが、読んだ文章**だけ**をもとにまとめる
3. AIが示した「根拠の一文」が本当にページ内にあるかを、**コードで照合**する
4. 照合できたものだけ「反映する」ボタンを出し、人が決める

3で、AIが根拠をでっち上げても見抜けるようにしています。
また、読み込んだページに指示のような文が仕込まれていても従わないよう、AIへの指示に明記しています（プロンプトインジェクション対策）。

## AI機能が claude.ai 上でだけ動く理由

AIアシストは、claude.ai の Artifact が提供する仕組み（`claude.use("sample")` でClaudeに質問、`claude.use("mcp")` でコネクタを呼ぶ）を使っています。
GitHub Pages で公開しているこのページには、AIを呼ぶための道具がないため、AIアシストのボタンは自動で隠れ、それ以外の機能だけが動きます。

「AIモデルは同じでも、道具を渡す外側の仕組み（ハーネス）がなければ動けない」ことを、実際に体験したポイントです。

## 技術

- HTML / CSS / JavaScript の1ファイルのみ（ライブラリなし）
- データはブラウザの `localStorage` に保存（サーバーには送らない）
- ライト・ダークモード対応、スマホ優先のレイアウト

主な関数：

| 関数 | 役割 |
|---|---|
| `allPairs()` | 28通りの組み合わせを作る |
| `calcScores()` | 回答から各軸の点数を数える |
| `matchScore()` | 合う度を計算する |
| `checkConds()` | 譲れない条件を満たしているか調べる |
| `insight()` | 合う度と直感のズレを判定する |
| `runResearch()` | ページを読み、AIにまとめさせ、根拠を照合する |

## プライバシー

入力した内容は、使っている端末のブラウザの中だけに保存されます。
AIアシスト（claude.ai 版）を使ったときだけ、その企業のメモとURLがAIに送られます。
「わたしの条件」は、自分でオンにしたときだけ送られます。
